Context

A training objective specifies what a model is asked to predict or optimize. Different objectives produce different learning signals. For GPT-style causal language modeling, predicting the next token is common; other model families and adaptation tasks may use different objectives.

The following mini-scenes are explanatory examples, not measured model outputs. Progress from the definition to a practical interview scenario.

What is a language model training objective?

Correct: D. A training objective defines what counts as a successful prediction and how mistakes generate a learning signal. In causal language modeling, the target is typically the next token. The loss turns prediction quality into a number that optimization can reduce. Choosing an objective shapes what the resulting model is encouraged to learn.

Why does an optimizer need a training loss rather than only a list of examples?

Correct: C. Examples alone do not tell an optimizer how to adjust numerical parameters. A loss function quantifies disagreement between outputs and intended targets, while differentiation gives update directions. Repeating that process over many batches helps improve the objective. However, a low training loss does not prove that deployment behavior is correct or safe.

How is the next-token prediction objective constructed for a causal language model?

Correct: B. Causal language modeling commonly shifts a token sequence so each position's target is the following token. A causal mask stops predictions from inspecting future positions. Cross-entropy can then measure the target token's probability. This creates many training positions from ordinary text and matches autoregressive generation at inference time.

What does cross-entropy loss encourage in next-token language modeling?

Correct: A. For a target token, cross-entropy penalizes the model when it assigns that token low probability. The loss aggregates such penalties across predicted positions, and gradients help adjust weights. This is a training signal about probability calibration for observed tokens, not a direct measure of factuality, harmlessness, or human satisfaction.

A dataset contains instruction-response pairs. What should be considered when choosing which tokens contribute to fine-tuning loss?

Correct: D. In supervised instruction tuning, teams often compute loss on target response tokens and may exclude prompt tokens from the loss. The exact scheme depends on the task and implementation. If boundaries or masks are wrong, the model may optimize irrelevant text. Inspect token labels and loss masks before trusting apparently good training metrics.

Why can a model with low next-token loss still fail a real business task?

Correct: B. Next-token loss measures prediction of observed training tokens, not the full quality of a deployed workflow. A model may score well yet give stale facts, unsupported claims, or malformed structured responses. Build task-level evaluations for correctness, format, safety, and user requirements. Good predictive modeling is useful but does not replace those checks.

A proposed training setup lets each token read future answer tokens while predicting them. What is the main issue for causal language modeling?

Correct: C. A causal language model must predict future tokens using only past and current context. If the training computation sees future targets, the loss can look artificially good because it has access to information unavailable at inference. Check causal masks, attention direction, and input-target alignment. The objective must match generation-time information limits.

An interviewer asks which training objective to use for a model that generates the next part of a document. Which answer is strongest?

Correct: A. For autoregressive continuation, next-token prediction is a natural training objective because generation proceeds token by token from preceding context. Implement shifted targets and causal masking, optimize a suitable loss, and test actual generated documents. Evaluations should include coherence and task requirements since token-level loss alone is not a complete quality measure.
