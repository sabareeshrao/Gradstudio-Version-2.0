# Spring PetClinic Visual Commit Atlas

Static visual-first education based on the original Spring PetClinic commit history.

- [Combined commits 1 and 2](https://sabareeshrao.github.io/Gradstudio-Version-2.0/spring-petclinic-visual/)
- [Commit 001](https://sabareeshrao.github.io/Gradstudio-Version-2.0/spring-petclinic-visual/commit-001.html)
- [Commit 002](https://sabareeshrao.github.io/Gradstudio-Version-2.0/spring-petclinic-visual/commit-002.html)

**Shared engine:** assets/visual.css (one design system), assets/engine.js (one static renderer), assets/lessons.js (only lesson-specific data). The HTML files are thin entrypoints; no duplicated page layout. No interactive controls or third-party dependencies.

Historical Git commit order is by parent ancestry rather than author dates: root 349fdef18bcf688709f19097c140c69724905768 → child f09d67cc1c216b445d01f1893f37ff391bb3b4b7. Their author dates appear out of order due to imported history. Commit 002 is explicitly marked work in progress, so not all features are claimed functional.

Pages deployment explicitly copies the spring-petclinic-visual folder into _site. Existing Gradstudio lessons and shared study-engine are unchanged.
