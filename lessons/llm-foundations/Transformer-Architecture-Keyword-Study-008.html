Context

The Transformer is a neural-network architecture that processes sequences using attention. Originally introduced for sequence-to-sequence tasks, it is also the foundation of many modern language models.

Understanding it starts with tokens and position information, then moves through attention, layers, model configurations, masking, and practical architecture choices.

Q1INTRODUCTION
01 / VISUAL CONCEPT

A stack of attention-based transformations

Illustrative mechanism · INPUT / ATTENTION / OUTPUT

1. What is the Transformer architecture, and which idea makes it different from older sequence models?

Correct: A. A Transformer is a neural-network design centered on attention. Instead of making every sequence position wait for the previous recurrent state, attention lets positions use information from other allowed positions. This supports efficient training on sequences. The original Transformer used encoder and decoder stacks; many current GPT models use decoder-only variants.
Q2FUNDAMENTALS
02 / VISUAL CONCEPT

Independent positions train in parallel

Illustrative mechanism · RECURRENT / PARALLEL / TRAIN

2. Why can Transformers process training sequences more efficiently than basic recurrent language models?

Correct: C. A basic recurrent model passes hidden information from one time step to the next, limiting parallel work. Transformer attention can process many positions together during training, using matrix operations on hardware suited to parallel computation. This does not mean generating a new autoregressive response becomes fully parallel; output tokens still depend on earlier generated tokens.
Q3WORKING MECHANISM
03 / VISUAL CONCEPT

Token identity meets position signal

Illustrative mechanism · TOKEN / POSITION / VECTOR

3. How do token embeddings and positional information prepare text before Transformer layers process it?

Correct: B. Text is first split into tokens. An embedding maps each token to a learned vector, which holds useful numeric features. Since attention alone does not automatically indicate sequence order, Transformers also use positional information. Together they help layers distinguish the same tokens appearing in different orders, an essential difference for understanding language.
Q4TECHNICAL UNDERSTANDING
04 / VISUAL CONCEPT

Attention scores relate token positions

Illustrative mechanism · QUERY / KEY / VALUE

4. What does self-attention help a Transformer represent when words depend on other words in a sentence?

Correct: D. Self-attention computes relationships between token representations using queries, keys, and values. A position can combine information from others that its attention mask allows. Different attention heads can capture different relationships. In the sentence 'The key fell because it was loose,' earlier words can help interpret 'it,' although actual weights vary.
Q5PRACTICAL APPLICATION
05 / VISUAL CONCEPT

Translation attends to source meaning

Illustrative mechanism · ENGLISH / CONTEXT / FRENCH

5. How would an encoder–decoder Transformer help translate a sentence from English into French?

Correct: A. In an encoder–decoder Transformer, the encoder reads the source sentence and builds context-aware representations. The decoder produces translated tokens while using its previous output and information from the encoder. This helps translation consider whole-sentence meaning, not only one-to-one word substitutions. The decoder still generates its target sequence in order.
Q6ADVANCED UNDERSTANDING
06 / VISUAL CONCEPT

A causal mask hides future tokens

Illustrative mechanism · PAST / CURRENT / FUTURE

6. Why does a GPT-style decoder use a causal attention mask during text generation?

Correct: C. A causal mask blocks attention from each sequence position to later positions. During training this prevents the model from using future target tokens to solve next-token prediction unfairly. At generation time, future tokens do not exist yet anyway. The mask keeps the training setup aligned with the model's left-to-right generation behavior.
Q7SMART-LEVEL REASONING
07 / VISUAL CONCEPT

Context separates two senses of bank

Illustrative mechanism · RIVER / BANK / MONEY

7. A model confuses 'bank' in 'river bank' with a financial bank. Which Transformer features could help?

Correct: B. A token's initial embedding alone may not express the meaning intended in a particular sentence. Transformer layers use attention and feed-forward transformations to create contextual representations. In 'river bank,' information about 'river' can influence how 'bank' is represented. This improves contextual interpretation, although ambiguous sentences can still challenge the model.
Q8INTERVIEW QUESTION
08 / VISUAL CONCEPT

Architectures match different tasks

Illustrative mechanism · ENCODER / DECODER / BOTH

8. You are designing translation, document classification, and chat features. How would you choose Transformer configurations and explain the trade-offs?

Correct: D. Encoder-style models often suit understanding or classification; decoder-style models suit open-ended generation; encoder–decoder models naturally fit input-to-output transformations such as translation. Real systems can use other configurations too. Choose through evaluation, not labels alone: compare accuracy, latency, training data, model size, maintenance costs, and needed output behavior.
