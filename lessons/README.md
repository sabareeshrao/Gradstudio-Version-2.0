## Shared study engine and quality standards

- **[All 21 hosted modules](https://sabareeshrao.github.io/Gradstudio-Version-2.0/study-engine/)** are recorded in the canonical [module manifest](../study-engine/modules/index.json). Each opens as an interactive GitHub Pages lesson without duplicating the shared HTML/CSS/JavaScript boilerplate.
- **Questions:** preserve supplied wording and ordering; remove only redundant leading `Layer N` prefixes; use four understandable A–D options with no correct-answer length clues.
- **Explanations:** default to a brief 18–30-word, beginner-friendly explanation. Longer technical reasoning stays in a collapsed **Read the detailed explanation** section.
- **Visuals:** use a custom illustrated introduction and one distinct instructional diagram per question, avoiding repeated generic text boxes. Check actual mobile and desktop rendering.
- **Validation:** [option balance](../study-engine/verify-module-options.mjs), [diagram quality](../study-engine/verify-diagram-quality.mjs), and [explanation quality](../study-engine/verify-explanation-quality.mjs). These automated checks do not replace human review.
- **Contributing new lessons:** follow the [shared study engine README](../study-engine/README.md) and add the topic JSON plus any diagram-specific styles; only create additional `lessons/` entrypoints when needed for ranked batches.

The original 16 standalone HTML lessons remain available in the archive, and the GitHub Pages deployment retains both historical root and nested lesson URLs.
