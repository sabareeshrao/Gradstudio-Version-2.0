# Telugu Translation — Gradstudio

This folder contains **separate Telugu-language copies** of current lessons in `lessons/`. **The English originals and their Study Engine modules are not modified.**

## Pilot: 01 — Transformer

- [Telugu lesson (HTML)](01-transformer.html)
- [Telugu content and seven preserved illustrations](transformer.te.json)
- [Browser preview](https://sabareeshrao.github.io/Gradstudio-Version-2.0/Telugu%20Translation/01-transformer.html)
- [English original](../lessons/01-transformer.html)

The original English `lessons/01-transformer.html` redirects to a Study Engine module; it is not a full standalone lesson. The Telugu entrypoint uses the existing shared styling and the seven original technical diagrams, with Telugu questions, answer options, explanations, section headings and diagram labels. Code and English sentence tokens remain as teaching examples; the model's answers and mechanics are unchanged.

**Translation policy:** Telugu script, concise beginner-friendly wording, technical terms retained when necessary, four balanced options per question, unchanged answer keys, translated diagram labels, optional detailed explanations, all 15 themes, and mobile-friendly layout.

Further lessons will be added only after this first translation is reviewed.
