Context

Generative Pre-trained Transformers (GPTs) are language models that learn patterns from large amounts of text. They use the Transformer architecture to predict tokens, generate responses, and support tasks such as writing, explanation, and summarization.

Understanding GPT starts with its name, training, and next-token generation, then moves into attention, context limits, instruction tuning, reliability, and how developers build useful applications around a model.

Three ideas make GPT

Illustrative mechanism · GENERATIVE / PRE-TRAINED / TRANSFORMER

1. What does Generative Pre-trained Transformer (GPT) mean, and what makes it a type of large language model?

Correct: B. Generative means producing new text. Pre-trained means learning language patterns from large datasets before a particular task. Transformer names the neural-network architecture that helps the model use context. GPT is an LLM because it learns from extensive text data and can produce language for many tasks.
Q2FUNDAMENTALS
02 / VISUAL CONCEPT

Training data reshapes model parameters

Illustrative mechanism · TOKENS / LOSS / WEIGHTS

2. What does GPT learn during pre-training, and why can it use that learning for many different text tasks?

Correct: D. During pre-training, GPT learns to predict text tokens from preceding context. Repeating this across diverse material develops useful patterns about language, facts and relationships. Those patterns can help with writing, summarizing and questions. Pre-training is not a live database lookup, and it does not guarantee every generated statement is correct.

3. How does GPT generate a response one token at a time after receiving a prompt?

Correct: A. GPT reads the tokens currently in its context and calculates possible next-token probabilities. A decoding method chooses a token. The model then uses the enlarged sequence to predict another, continuing until it stops. Tokens may represent words, word pieces or punctuation. This is a simplified description of autoregressive generation.

4. How does the Transformer’s attention mechanism help GPT use earlier words when predicting what comes next?

Correct: C. The Transformer uses self-attention to combine information from different positions in the context. In a causal GPT model, a position can use earlier positions but not future tokens. This helps connect related words across a sentence. Attention weights are learned and complex; a simple highlighted link is only an illustration.

5. What is GPT’s context window, and why does it matter when a user supplies a long document?

Correct: D. The context window limits how many tokens GPT can consider in an interaction. Prompts, supplied documents and generated output use available space, depending on the system. If content is too long, an application may split, summarize or retrieve relevant sections. A larger window helps, but does not guarantee perfect recall.
Q6ADVANCED UNDERSTANDING
06 / VISUAL CONCEPT

Instruction tuning changes answer behavior

Illustrative mechanism · BASE / TUNED / REQUEST

6. Why might a GPT model need instruction tuning before it works well as a helpful chat assistant?

Correct: B. A base GPT model mainly learns to continue text from pre-training. Instruction tuning uses examples of requests and suitable responses to improve how it follows users’ instructions. Human feedback may further guide behavior. These methods improve helpfulness, but they do not remove uncertainty, mistakes or the need to evaluate outputs.
Q7SMART-LEVEL REASONING
07 / VISUAL CONCEPT

Retrieved evidence corrects outdated claims

Illustrative mechanism · OLD POLICY / CURRENT / VERIFY

7. GPT confidently states an old refund policy, but the company updated it yesterday. Why can this happen, and how should an application respond?

Correct: C. A fluent answer is not proof of current or correct information. A model may rely on outdated learned patterns or incomplete context. For changing policies, retrieve the approved current document, include its relevant text, and check the response. When evidence is missing, say so rather than inventing a policy.
Q8INTERVIEW QUESTION
08 / VISUAL CONCEPT

Reliable assistant uses evidence and checks

Illustrative mechanism · RETRIEVE / VERIFY / ANSWER

8. In an interview, you are asked to build a GPT-powered customer-support assistant that answers questions using changing company documents. How would you design it for accuracy, speed, cost, and safety?

Correct: A. Start with trusted documents and retrieval so answers use current evidence. Check who can access each document, show sources where possible, and define a safe fallback when evidence is weak. Measure accuracy, latency and cost using real support questions. Cache suitable information and escalate sensitive cases to people.
