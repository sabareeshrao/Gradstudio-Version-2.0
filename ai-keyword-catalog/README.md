# AI Keyword Catalog — 4,857 Unique Keywords Across 43 Domains

A curated, non-overlapping AI terminology master list for gradual learning, from foundational AI and mathematics through machine learning, LLMs, robotics, scientific AI and quantum ML.

**Inventory (2026-10-30):** 4,857 enumerated terms; **43** primary domains. The earlier 3,520 figure was a planning estimate, not an imposed quota. This list is an extensible curriculum, not a claim to contain every AI term ever coined.

## Files

- [ALL_KEYWORDS.md](ALL_KEYWORDS.md) — every keyword in one numbered Markdown file, grouped by domain.
- [keywords.csv](keywords.csv) — UTF-8 spreadsheet-ready index containing global ID, domain ID, domain name, and keyword.
- The 43 domain files below — each keyword has one primary domain, making them suitable for separate learning modules.

## Deduplication and ownership rules

1. A keyword appears only once in this catalog, under its most appropriate **primary domain**. Related terms (for example, *Transformer* and *Vision Transformer*) are different named concepts and remain separate.
2. Case, whitespace, punctuation and Unicode compatibility differences are normalized for an exact-name uniqueness check.
3. Obvious full-term/acronym pairs (such as *Physics-informed neural network (PINN)*) are combined into one entry. Acronyms that mean something else in context are not collapsed.
4. Cross-domain topics should link back to their owning keyword instead of copying it. The [existing 265-rank LLM curriculum](../KEYWORD_INDEX.md) remains separate and unchanged; it is a lesson progress tracker, not a second copy inside this catalog.
5. Future additions should run a duplicate audit and update the counts and consolidated indexes.

## Learning workflow

For each keyword, generate progressive learning layers and questions in the repo's established [study-module standard](../docs/STUDY_MODULE_BUILD_STANDARD.md), without treating this inventory as already-completed lessons. The catalog files are terminology only; no HTML module or quiz has been generated by this commit.
